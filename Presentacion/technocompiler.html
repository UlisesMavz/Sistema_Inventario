01
Propósito y Objetivo Tecnológico
▾

El TECHNOCOMPILER tiene como finalidad demostrar la aplicación práctica de la teoría de compiladores mediante el desarrollo de una herramienta funcional capaz de analizar código real.

  • Analizar archivos C++ completos
  • Detectar estructuras de control (while, do-while, asignaciones)
  • Generar representación intermedia (IR) con etiquetas de salto
  • Aplicar optimizaciones automáticas como Constant Folding
  • Generar código C++ optimizado como salida
02
Metodología Implementada
▾

Se implementó una arquitectura basada en fases clásicas de compilador, siguiendo el modelo de compiladores industriales como GCC y LLVM:

  • Programación modular: cada fase es independiente y autocontenida
  • Escalabilidad: permite agregar nuevas fases sin afectar las existentes
  • Separación de responsabilidades: lexer, parser, IR, optimizador y reconstructor operan de forma desacoplada

04
Análisis Léxico — Lexer
▾

El Lexer convierte el código fuente en una secuencia de tokens usando expresiones regulares. Es el primer módulo del pipeline.

  • Detecta identificadores (\w+), operadores compuestos (==, !=, <=, >=) y símbolos de control
  • Retorna una lista plana de strings que el Parser consume
# Expresión regular del lexer def lexer(codigo): tokens = re.findall( r"\w+|==|!=|<=|>=|[+\-*/=;(){}<>]", codigo) return tokens
05
Análisis Sintáctico — Parser & AST
▾

El Parser construye el Árbol de Sintaxis Abstracta (AST) recorriendo el código línea por línea. Cada estructura de control se convierte en un nodo del árbol con sus hijos anidados.

  • while(cond){...} → Nodo WHILE con hijos: condición y cuerpo
  • do{...}while(cond); → Nodo DO_WHILE con cuerpo y condición
  • var = expr; → Nodo ASIGNACION con variable y expresión

Árbol AST — Estructura jerárquica del programa

🌿 Programa (raíz)

Nodo raíz del árbol. Contiene todos los nodos de nivel superior: asignaciones y estructuras de control.

🔁 While

Nodo de estructura de control. Sus hijos son la condición (expresión booleana) y el cuerpo (lista de nodos).

📝 Asignación

Nodo hoja con una variable y su expresión. Puede aparecer en nivel raíz o dentro del cuerpo de un While.

class Nodo: # tipo: WHILE | DO_WHILE | ASIGNACION def __init__(self, tipo, valor=None, izq=None, der=None, cuerpo=None): self.tipo = tipo # tipo de nodo self.valor = valor # condición o nombre de variable self.izq = izq # expresión izquierda self.cuerpo = cuerpo # lista de nodos hijos
06
Generación de IR — Representación Intermedia
▾

La IR transforma el AST en instrucciones simples con etiquetas de salto, similar al bytecode de compiladores reales.

  • Asignaciones: a = expresión
  • Condicionales de salto: if !(condición) goto Lx
  • Saltos incondicionales: goto Lx
  • Etiquetas: L0:, L1:
# IR generada para while(a<10) L0: if !(a<10) goto L1 a = a + 1; goto L0 L1:
07
Optimización — Constant Folding
▾

El optimizador aplica Constant Folding: evalúa en tiempo de compilación expresiones formadas únicamente por constantes literales.

  • Detecta patrón: var = número OP número
  • Evalúa la expresión y reemplaza con el resultado
  • Ejemplo: a = 2 + 3 → a = 5
08
Autómata Finito — Base del Lexer
▾

El análisis léxico se fundamenta en un Autómata Finito Determinista (AFD). Las expresiones regulares usadas en el lexer son equivalentes formales de AFDs.

  • Un conjunto de estados que representan el avance en el reconocimiento
  • Un alfabeto de símbolos válidos (caracteres C++)
  • Una función de transición que define el siguiente estado
  • Un estado inicial y estados de aceptación para cada tipo de token

📦 Clase Nodo — Estructura del AST

Define el nodo básico del Árbol de Sintaxis Abstracta. Cada nodo tiene tipo, valor y punteros a sus hijos.

class Nodo: def __init__(self, tipo, valor=None, izq=None, der=None, cuerpo=None): self.tipo = tipo self.valor = valor self.izq = izq self.der = der self.cuerpo = cuerpo

🔤 Lexer — Análisis Léxico

Tokeniza el código fuente completo en una sola pasada con una expresión regular.

def lexer(codigo): tokens = re.findall( r"\w+|==|!=|<=|>=|[+\-*/=;(){}<>]", codigo) return tokens

🌳 Parser — Análisis Sintáctico

Recorre el código línea por línea detectando estructuras y construyendo nodos del AST.

def parser(codigo): ast = [] lineas = codigo.splitlines() i = 0 while i < len(lineas): match_while = re.match(r"while\s*\((.+)\)", lineas[i].strip()) if match_while: condicion = match_while.group(1) cuerpo = [] i += 1 while "}" not in lineas[i]: cuerpo.append(lineas[i]); i += 1 ast.append(Nodo("WHILE", condicion, cuerpo=cuerpo)) # ... do-while, asignaciones similares

📋 Generar IR

Transforma nodos AST en instrucciones lineales con etiquetas de salto.

def generar_ir(ast): ir = []; label_count = 0 for nodo in ast: if nodo.tipo == "WHILE": Lstart = f"L{label_count}"; label_count += 1 Lend = f"L{label_count}"; label_count += 1 ir.append(f"{Lstart}:") ir.append(f"if !({nodo.valor}) goto {Lend}") for l in nodo.cuerpo: ir.append(l.strip()) ir.append(f"goto {Lstart}") ir.append(f"{Lend}:")

⚡ Optimizador — Constant Folding

Detecta y evalúa expresiones de constantes en tiempo de compilación.

def optimizar_ir(ir): nueva_ir = [] for instr in ir: match = re.match( r"(\w+)\s*=\s*(\d+)\s*([+\-*/])\s*(\d+)", instr) if match: var, a, op, b = match.groups() nueva_ir.append(f"{var} = {eval(f'{a}{op}{b}')}") continue nueva_ir.append(instr) return nueva_ir

🔧 Reconstructor — Código Final

Aplica optimizaciones sobre el código original manteniendo su estructura.

def reconstruir_codigo(codigo_original, ir_opt): codigo_final = codigo_original for instr in ir_opt: match = re.match(r"(\w+)\s*=\s*(\d+)", instr) if match: var, valor = match.groups() codigo_final = re.sub( rf"{var}\s*=\s*[^;]+;", f"{var} = {valor};", codigo_final) return "//Codigo optimizado por TECHNOCOMPILER V7//\n" + codigo_final

🚀 Main — Control General

Orquesta todas las fases del compilador y gestiona la entrada/salida.

def main(): ruta = input("Ruta del archivo .cpp: ") with open(ruta, "r") as f: codigo = f.read() tokens = lexer(codigo) ast = parser(codigo) ir = generar_ir(ast) ir_opt = optimizar_ir(ir) codigo_final = reconstruir_codigo(codigo, ir_opt) with open("optimizado_" + os.path.basename(ruta), "w") as f: f.write(codigo_final) generar_reporte_txt(tokens, ast, ir, ir_opt)

Limitaciones & Soluciones Futuras

⚠ Limitaciones Actuales

  • Parser limitado: Solo detecta while, do-while y asignaciones simples
  • Sin validación sintáctica: No detecta errores como paréntesis no cerrados
  • Sin tabla de símbolos: No valida declaración de variables
  • Sin soporte de IF: No maneja condicionales if/else
  • Sin funciones ni tipos: No procesa funciones, arrays, ni tipos de datos

✅ Soluciones Futuras

  • Gramática formal BNF: Parser robusto basado en gramática
  • Tabla de símbolos: Validar declaración y tipos de variables
  • Type checking: Detectar errores de tipos en compilación
  • Implementar IF/ELSE: Ampliar el parser con control condicional
  • Dead code elimination: Eliminar código inalcanzable
  • Propagación de constantes: Optimización avanzada entre instrucciones
